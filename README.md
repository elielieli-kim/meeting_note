# 🎙️ 동아리 회의록 자동 생성기 (Meeting Minutes Maker)

녹음 파일(M4A, MP3, WAV 등) 또는 대화 스크립트를 입력하면, 정해진 기준에 맞춰 표준 동아리 회의록을 자동으로 생성하는 웹 시스템입니다.

---

## 📌 주요 특징 및 화면 구성

1. **기본 화면 제공**
   - 첫 실행 시 전달해주신 **Hanyang University 2 (동아리 회의)** 녹음본의 정리 결과가 기본으로 표시됩니다.
2. **새로운 녹음본 입력 및 자동 분석 시스템**
   - **오디오 파일 업로드**: M4A, MP3, WAV, AAC, MP4 파일을 드래그 & 드롭하여 업로드 및 재생 가능.
   - **녹취 텍스트 입력**: 클로바노트, Whisper 등으로 추출된 스크립트나 회의 내용을 직접 붙여넣어 생성 가능.
   - **Gemini 멀티모달 AI 연동 지원**: 상단 [API 설정]에 Google AI Studio 무료 API Key를 입력하면, 대용량 오디오를 직접 청취하고 정밀하게 회의록을 생성합니다.
   - **내장 스마트 분석 엔진**: 별도의 API 키 없이도 텍스트 규칙 분석 엔진을 통해 즉시 표준 회의록을 추출합니다.
3. **엄격한 작성 규칙 준수**
   - **[요약]**: 정확히 세 줄 요약
   - **[결정 사항]**: 회의에서 확정된 안건만 `~하기로 했다` 형식으로 끝맺음 (단순 논의/이야기만 나온 안건은 자동 제외)
   - **[할 일]**: 표 형식 (`할 일` / `담당` / `마감`), 정해지지 않은 항목은 반드시 `미정` 처리
   - **사실 준수**: 녹음에 등장하지 않은 내용·날짜·사람은 쓰지 않음
4. **편의 기능**
   - 📋 텍스트 클립보드 원클릭 복사
   - 💾 Markdown (`.md`) 파일 다운로드
   - 📜 생성 이력 히스토리 보관

## 🚀 실행 방법

### 방법 1: 브라우저에서 바로 열기
작업 폴더의 `index.html` 파일을 더블클릭하여 Chrome, Safari, Edge 등의 브라우저에서 바로 열 수 있습니다.

### 방법 2: 로컬 웹 서버 실행 (권장)
터미널에서 아래 명령어를 실행하면 브라우저 창이 자동으로 열립니다:
```bash
python3 server.py
```
접속 주소: [http://localhost:8080/index.html](http://localhost:8080/index.html)
